# 单词混记 (WordMix) · 安卓端新机快速使用说明书

> 本说明书专为**在新手机上安装和使用「单词混记」App** 的用户编写。  
> 按照以下 4 个步骤，只需 **1 分钟** 即可完成新机配置、拉取全部词库并开启高效抗遗忘背词！

---

## 📱 一、下载与安装

### 1.1 获取安装包 (APK)
在手机自带浏览器中直接访问以下官方下载地址（或通过电脑传到手机）：
* **直接下载链接**：  
  👉 `http://<你的服务器地址>:18080/app/download/wordmix.apk`
* **本地安装包**：仓库 `dist/单词混记.apk`（大小约 2.4 MB，体积极其小巧）。

### 1.2 安装时的权限提示处理
由于本 App 属于个人私有开发的独立原生应用，未上架商业手机应用商店，手机系统可能会弹出安全提示：
* **华为 / 荣耀**：若提示“应用未在华为应用市场经过安全检测”，点击底部的 **「继续安装」** 或选择输入锁屏密码安装。
* **小米 / 红米**：若提示“未知应用来源”，在弹窗中勾选“我已了解风险”，点击 **「允许本次安装」**。
* **OPPO / vivo**：点击 **「无视风险安装」** 或输入账号密码安装。
* **通用权限**：安装完成后首次启动，如果询问网络访问权限，请选择 **「允许访问移动网络和 WLAN」**。

## 🚀 二、首次启动与连接云端同步

安装完成后，打开「单词混记」App。新安装的 App 本地词库为空，只需一次配置即可将云端保存的所有单词完整拉取到手机。

### 2.1 打开设置
点击主界面右上角的 **「⚙️ 设置」** 或 **「🔄 同步」** 按钮，打开配置面板。

### 2.2 填写同步凭据
在弹出的配置框中输入服务器地址与专属同步令牌（Token）：
* **服务器地址 (URL)**：`http://<你的服务器IP或域名>:18080`（本地局域网演示填 `http://192.168.x.x:8000`）
* **同步令牌 (Token)**：输入专属 Token（注意无需前缀 `Bearer `）
  > 💡 **小贴士**：Token 属于敏感凭据，请向管理员获取或从服务器端获取。

### 2.3 触发全量对齐
点击面板上的 **「立即同步」** 按钮：
* App 将在 1~2 秒内自动连接云端，拉取所有易混淆词组与单词。
* 同步成功后，主界面底部会显示类似：`已同步 52 组 / 101 词 (版本 #105)`。
* 恭喜！你的新手机已经与云端完全对齐，可以开始背诵了！

## 💡 三、核心背诵与自测功能操作指南

### 3.1 横向分组标签（快速切组）
* 顶部有一排**横向滑动的分组胶囊标签**（如 `plague/plight`、`contract/contact/contrast` 等）。
* 点击某个标签：列表立即仅展示该分组下的易混淆单词。
* 点击最左侧的「全部」：还原展示全部词条。

### 3.2 抗遗忘遮挡自测（核心背诵技巧）
* **默认状态**：每个单词卡片下方，中文释义默认被一条**灰色圆角遮挡长条**覆盖。
* **自测步骤**：
  1. 看着英文单词，在脑海中回忆它的中文含义与容易混淆的近形词。
  2. **点击灰色长条**：遮挡条消失，露出真正的中文释义，核对记忆是否正确。
  3. **再次点击释义**：重新盖上遮挡条，方便多轮重复自测。

### 3.3 单词发音（系统 TTS）
* 每个单词右侧均带有音标和发音图标。
* **点击音标或发音按钮**：手机会即刻朗读纯正英语发音。
  > 📢 若没有声音，请检查手机媒体音量，或在手机「系统设置 -> 文本转语音 (TTS)」中确认已安装 Google TTS 或系统自带英语语音包。

### 3.4 快速搜索
* 顶部提供实时搜索框，支持**英文单词前缀**与**中文释义模糊匹配**。
* 随着键入字符，列表瞬时过滤，找词秒开。

### 3.5 录入新词与编辑
* **添加新词/新组**：
  * 点击右下角的 **「＋」浮动按钮**。
  * 选择归入已有分组，或直接输入新分组名称。
  * 录入单词与释义，系统会自动联网或查本地离线词典补充国际音标，并推荐相近的易混淆词。
* **修改或删除**：
  * 长按任意词条卡片，弹出快捷操作菜单（编辑、删除、朗读、复制）。

## 🌐 四、离线使用与多端自动协同

* **无网络环境（地铁、飞行模式）畅快用**：
  * 单词混记遵循 **Offline-First（离线优先）** 原则。
  * 在没有网络时，所有查询、自测、修改或新加单词都可以照常进行，所有操作均安全缓存在手机本地。
* **连网后一键追更**：
  * 重新连上 Wi-Fi 或移动数据后，只需点击一下右上角 **「同步」**。
  * 手机本地记录的操作日志会自动追推到服务器，无论电脑 Web 端如何修改，两端都会基于操作版本自愈对齐，**绝不丢失数据**。

## 🔄 五、一键应用内自更新（无需手动拷包）

以后发布新版本时，**再也不需要手动下载 APK 覆盖安装**：

1. **自动感知**：当有新版 APK 发布时，打开 App 或在设置中点击 **「检查更新」**，会自动弹出新版提示及更新日志（Changelog）。
2. **一键下载安装**：
   * 点击弹窗中的 **「立即更新」**。
   * App 会在后台高速下载新安装包并自动校验完整性。
   * 下载完成后会自动调起系统安装确认页面，点击 **「安装 / 更新」** 即可无缝升级，本地数据与登录配置完整保留！

## ❓ 六、常见问题排查 (FAQ)

### Q1：点击“立即同步”提示网络错误或超时？
1. 检查手机是否连接了正常的网络（或是否给 App 开了 WLAN/蜂窝数据权限）。
2. 确认服务器地址前缀带 `http://`，端口号是否正确（默认为 `18080` 或 `8000`）。
3. 检查 Token 是否多输或漏输了字符。

### Q2：为什么部分单词点击没有发音？
* 本 App 使用 Android 系统原生的 Text-to-Speech (TTS) 引擎。
* 请进入手机的 **系统设置** $\rightarrow$ **辅助功能 / 更多设置** $\rightarrow$ **文本转语音 (TTS)**，确认当前引擎支持英语发音，并建议下载 Google 文字转语音的“英语（美国）”语音数据包。

### Q3：换了新手机后，旧手机上的数据会丢吗？
* 只要你在旧手机上点过同步，数据就已经永久保存在云端。在新手机上填好服务器地址和 Token 点一次同步，全部单词就会瞬间完整同步过来。
